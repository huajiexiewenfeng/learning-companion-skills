Misconception

误区：完整的 Memory 就是当前事实

错误。Memory 即使完整也只是压缩上下文；Archive 是历史证据，Plan 是意图，Checkpoint 决定转换，Authoritative State 保存当前事实，Trace 记录实际发生的结果。

Common shortcut

Treating a plausible answer as a completed outcome bypasses system controls.

Better check

Confirm the evidence, state transition, and approval path.
