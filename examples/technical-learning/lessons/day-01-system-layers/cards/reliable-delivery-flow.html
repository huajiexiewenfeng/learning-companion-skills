可靠交付流：证据到验收的受控路径

Archive 和当前来源提供输入，Plan 经 Checkpoint 核验后才可写入 Authoritative State，并由 Trace 支撑验收。

  1. Archive / 当前来源区分历史证据和 Memorysuccess
  2. Plan候选步骤，不等于执行结果active
  3. Checkpoint核验权限、前置条件和批准gate
  4. Authoritative State写入已发生的受控结果risk
  5. Trace 与验收连接输入、操作、状态与可靠交付success
  6. Archive / 当前来源 形成候选 Plan
  7. Plan 等待核验 Checkpoint
  8. Checkpoint 批准执行 Authoritative State
  9. Authoritative State 记录结果 Trace 与验收
