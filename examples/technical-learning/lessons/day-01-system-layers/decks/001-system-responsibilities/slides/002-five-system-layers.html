五层企业 AI 系统分层

每一层都有清楚的责任边界：意图、运行时、知识记忆、治理工作流，以及权威状态与可观测性。

  1. 体验与意图层目标、约束与验收，不声明业务事实neutral
  2. 模型与代理运行时模型能力提出候选与工具请求active
  3. 知识与记忆层：Archive / MemoryArchive 留证据；Memory 提供可过期的压缩上下文success
  4. 工作流与治理层：Plan / CheckpointPlan 表示意图；Checkpoint 核验权限和前置条件gate
  5. 权威状态与可观测层：Authoritative State / Trace当前事实与实际事件链，支撑系统能力risk
  6. 体验与意图层 表达目标 模型与代理运行时
  7. 模型与代理运行时 请求证据 知识与记忆层：Archive / Memory
  8. 知识与记忆层：Archive / Memory 提供依据 工作流与治理层：Plan / Checkpoint
  9. 工作流与治理层：Plan / Checkpoint 受控转换 权威状态与可观测层：Authoritative State / Trace
