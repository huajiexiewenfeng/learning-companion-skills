责任图：建议、控制与事实不能混在一起

责任图把人和业务、AI 运行时、系统记录与治理分开；只有受控操作才可改变 Authoritative State。

  1. 业务负责人拥有目标、约束和验收neutral人和业务
  2. AI 代理形成 Plan 与候选操作active模型运行时
  3. Archive 与 Memory提供历史证据与可复用上下文success系统记录与治理
  4. Checkpoint检查权限、前置条件和审批gate系统记录与治理
  5. Authoritative State保存当前事实与状态转换risk系统记录与治理
  6. Trace证明输入、执行与结果的联系success系统记录与治理
  7. 业务负责人 给出目标 AI 代理
  8. AI 代理 读取证据 Archive 与 Memory
  9. AI 代理 提交受控请求 Checkpoint
  10. Archive 与 Memory 核对依据 Checkpoint
  11. Checkpoint 允许写入 Authoritative State
  12. Authoritative State 追加事件 Trace
  13. Trace 支持验收 业务负责人
